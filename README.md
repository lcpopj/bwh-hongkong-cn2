## 一、为什么香港VPS测评要看线路，而不是只看配置

很多人挑VPS习惯先比CPU、内存、硬盘，再看价格。这套逻辑在美国机房基本成立，因为美西机房到国内都要走太平洋海底光缆，线路差异没那么夸张。香港不一样——同一个机房、同一台物理机，走CN2 GIA和走普通163网络，晚高峰延迟能差一倍，丢包率能从0飙到30%。

中国电信到香港有四条主要线路，从便宜到贵依次是：

- **AS4134（ChinaNet/163）**：最常见也最拥堵，晚高峰丢包率能到30%以上，便宜但不可靠
- **AS4809 CN2 GT（Global Transit）**：原本用来解决163拥堵，2019年后自己也堵了，性价比很低
- **AS4809 CN2 GIA（Global Internet Access）**：最贵也最稳，CN2 GIA的IP transit价格能到每兆$120，1Gbps满带宽一个月账单理论上能到$10万级别
- **AS23764 CTGNet**：中国电信新推出的线路，实际表现和CN2 GIA接近

## 三、速度测试：1Gbps带宽国内能跑多少

搬瓦工香港套餐全部标配1Gbps带宽，这在香港VPS里相当少见——大多数香港VPS给的是10Mbps、50Mbps，100Mbps都算大带宽。1Gbps的峰值带宽到国内实际能跑多少？

公开测评显示，晚高峰时段电信和移动都能跑到接近400Mbps，联通也有200Mbps左右。这个速度建站绰绰有余，图片站、视频站、电商站都能扛得住。如果是做跨境文件传输、数据同步，400Mbps相当于50MB/s的实际传输速度，日常使用完全够。

不过要注意，1Gbps是共享带宽上限，不是独享。搬瓦工官方在TOS里也写明了不同套餐的CPU分配比例，高配套餐能拿到更多核心资源，低配套餐在高峰期可能会被限制。这也是为什么入门套餐$89.99/月看着贵，但和别家香港VPS比，1Gbps带宽本身就是溢价点。

## 四、丢包率：晚高峰0丢包是真的

丢包率是建站用户最容易忽略、但实际影响最大的指标。丢包率高的时候，网站打开速度会变慢甚至打不开，SSH连接会卡顿，跨境视频会议会掉线。

公开测评显示，搬瓦工香港CN2 GIA机房在晚高峰（晚上8点半）测试，国内三网节点丢包率为0。这个表现主要归功于CN2 GIA线路本身容量有限但稳定性极高，加上搬瓦工自己的网络监控——官方说所有VPS节点每分钟检查一次故障和过载。

需要说明的是，CN2 GIA线路对DDoS攻击的容忍度很低，遇到攻击时搬瓦工会采用IP nullrouting（空路由）处理，这时候你的VPS会暂时不可达。如果你的业务容易招DDoS，CN2 GIA不是最佳选择，搬瓦工的洛杉矶CN2 GIA-E或者普通163线路抗DDoS能力更强。

路由决定了数据从国内到香港走哪条路。搬瓦工香港机房的路由结构是：
